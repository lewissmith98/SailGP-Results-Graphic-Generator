America's Cup Results Generator

Fleet racing standings and event-standings graphics for the America's Cup — a separate tool from the SailGP generator, same look.

In Google Sheets: File → Download → CSV (or .xlsx), then choose it here.
Expected columns: team_name, short_team_name, country_code, skipper_first_name, skipper_surname, then per event: <event>_r1_position … _r8_position (1–9), each paired with <event>_r<N>_penalties — leave blank for a clean finish, or put DNS / DNF / RET / DSQ there to override the scored result for that race, or a signed number (-2, +3) to adjust that race's points. <event>_r-match_position / _r-match_penalties capture the winner-takes-all match race between the top two boats, in the same format as a normal race — fill these in once the match has been sailed and the winner is automatically ranked 1st, the loser 2nd, overall. Everyone else is still ranked by fleet points, with ties broken by finishing place in the most recent shared race. Every row's badge is its country flag with a colour tab: blue for the senior boat, grey for a women's/youth boat — worked out from the team name, or set it explicitly with an optional crew_type column (senior / women_youth).
